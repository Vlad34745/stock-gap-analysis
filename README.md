# Stock Gap & Price Action Analysis Automation

A professional Python-based automated analytical tool that fetches historical market data, identifies significant opening gaps, and calculates subsequent short-term asset price actions.

## 🚀 Features
* **Automated Data Fetching:** Seamless integration with Yahoo Finance API.
* **Smart Filtering:** Dynamically detects opening gaps greater than 1.5%.
* **Predictive Math Logic:** Calculates subsequent price movements for Day 2 and Day 3 using Pandas.
* **Financial-Grade Export:** Generates visually polished Excel reports (`.xlsx`) matching professional corporate standards (Emerald Theme, conditional color-coding for profits/losses, dynamic formulas, and accounting lines).

## 🛠️ Tech Stack
* **Python 3.x**
* **Pandas** (Data wrangling & quantitative calculations)
* **yfinance** (Financial market data ingestion)
* **OpenPyXL** (Advanced Excel formatting & workbook automation)
